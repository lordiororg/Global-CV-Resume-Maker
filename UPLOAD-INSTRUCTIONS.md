# Files to upload to GitHub

Six files changed. Each keeps its original path, so you can drag them onto the matching
folder in the GitHub web uploader (or copy them over your local clone and commit).

| File here | Goes to | What it does |
|---|---|---|
| `index.html` | `index.html` | Adds the template-pool container in step 2, the download-checklist container in step 4, the `src/ai.js` script tag and the **AI remap** panel inside the **Extraction review** drawer. |
| `README.md` | `README.md` | Documents the template pools by region and the download-check codes. |

| `src/app.js` | `src/app.js` | Template pool UI and switching, the download-check gate (CV-101 to CV-119) on Word, PDF and print, the checklist under the review chips, the AI remap wiring, and the earlier PDF-export fix. |
| `src/styles.css` | `src/styles.css` | Styles for the template cards and the download-check panel (plus the AI panel and the earlier long-date wrap rule). |

Nothing else changed. `dist/` is generated by `npm run build`, so it does not need uploading —
the GitHub Actions workflow rebuilds it before deploying.

## Template pool

Step 2 now shows a pool of layouts for the chosen country. The first card is marked
**Most preferred in <country>** and is applied automatically. Clicking another card changes
only the layout — content, country rules, Word and PDF output are untouched. "Use the most
preferred template" switches back.

## Download checks

Word, PDF and Print refuse to start while the CV is incomplete and print a code for each gap
(for example `CV-104` for a malformed email, `CV-114` for a country that expects a photo,
`CV-119` for a country that expects named referees), with the fix and a **Fix in step 3**
button. Unticking a detail under **Show** in step 2 removes its check.

## About the AI key

No API key is in the code. Each person pastes their own free key from
<https://aistudio.google.com/apikey> into the app; it is stored in that browser's
`localStorage` and sent only to Google. The free tier covers this use comfortably:
the app picks a Flash-Lite model, which allows roughly 500 requests a day at no cost and
needs no card. Only one request is made per upload.

If the key is missing, rejected, or the daily quota is gone, the app says so and the
rule-based mapping stays exactly as it was.
